# Profile assets

The profile uses local SVGs so its images do not depend on a badge service, API quota, or scheduled workflow. The header is original artwork with light and dark variants selected by a GitHub-compatible `<picture>` element. All essential profile information also appears as text in the main README.

## Technology icons

- **Devicon:** HTML, CSS, JavaScript, Java, Tailwind CSS, Bootstrap, PHP, MySQL, Git, GitHub, VS Code, Docker, and PowerShell. Source: [devicons/devicon at `7330acc`](https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58/icons). See [the included MIT license](icons/LICENSE-devicon.txt).
- **Simple Icons:** Google Apps Script, Google Sheets, and XAMPP. Source: [simple-icons/simple-icons at `d4e6ba9`](https://github.com/simple-icons/simple-icons/tree/d4e6ba93e48f178898707f0145ec285f28b64b38/icons). See [the included CC0 license](icons/LICENSE-simple-icons.txt).

Brand marks belong to their respective owners. Icons are presented on small pale tiles for visibility in both GitHub themes; Simple Icons marks use brand colors. Keep source and license information when replacing icons.
